## 🇨🇳 中文版

### 📦 关于本资源包

本资源包将原版《我的世界》及部分模组的 GUI 全面改造为**机械动力（Create）风格**。

### ✨ 主要特性

- 全面覆盖原版所有容器界面，包括工作台、铁砧、熔炉、酿造台、箱子等
- 额外适配精致存储（Refined Storage）等常用模组的 GUI

### 📥 安装方法

1. 下载本资源包（`.zip` 文件）
2. 打开 Minecraft，进入 **选项 → 资源包**
3. 将下载的 `.zip` 拖入资源包界面
4. 启用并加载即可

> 💡 推荐配合 **机械动力（Create）** 模组使用以获得完整视觉体验。

| **推荐搭配** | 机械动力（Create）模组 |

## 🇬🇧 English Version

### 📦 About This Pack

This resource pack overhauls the GUI of vanilla Minecraft and several mods to match the **Create mod** style.

### ✨ Key Features

- Full coverage of all vanilla containers: crafting table, anvil, furnace, brewing stand, chests, and more
- Additional support for popular mod GUIs such as Refined Storage

### 📥 Installation

1. Download the resource pack (`.zip` file)
2. Launch Minecraft and go to **Options → Resource Packs**
3. Drag the downloaded `.zip` file into the resource pack interface
4. Enable and load the pack

> 💡 Recommended to use alongside the **Create** mod for the complete visual experience.

### 🔧 Compatibility

| Item | Info |
|------|------|
| **Game Versions** | Priority support for Minecraft **1.21.1** – other versions (e.g., 1.20.1) are currently being adapted |
| **Recommended** | Create mod |
