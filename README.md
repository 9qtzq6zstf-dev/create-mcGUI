# 🏭 Create MC GUI

[![CurseForge](https://img.shields.io/badge/CurseForge-下载-orange?style=flat&logo=curseforge)](https://www.curseforge.com/minecraft/texture-packs/create-mcgui)

Change the GUI of vanilla and some mods to the Create style.

---

## 🇨🇳 中文版

### 📦 关于本资源包

本资源包将原版《我的世界》及部分模组的 GUI 全面改造为**机械动力（Create）风格**。

### ✨ 主要特性

- 全面覆盖原版所有容器界面，包括工作台、铁砧、熔炉、酿造台等。
- 扩展了对热门模组 GUI 的兼容，包括：
  - Create（机械动力） 及其生态
  - Farmer's Delight（农夫乐事）（烹饪与农耕）
  - JEI（Just Enough Items）（配方查看）
  - Curios API（饰品栏）（饰品槽位）
  - Touhou Little Maid（车万女仆）（女仆实体 GUI）

### 📥 安装方法

1. 请前往 [CurseForge](https://www.curseforge.com/minecraft/texture-packs/create-mcgui) 下载本资源包（`.zip` 文件），以支持正规分发。
2. 打开 Minecraft，进入 **选项 → 资源包**
3. 将下载的 `.zip` 拖入资源包界面
4. 启用并加载即可

> 💡 推荐配合 **机械动力（Create）** 模组使用以获得完整视觉体验。
